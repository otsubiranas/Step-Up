# Step Up Figueres — Landing Page

Landing page estàtica preparada per publicar a GitHub Pages.

## Publicació ràpida a GitHub Pages

1. Crea un repositori nou a GitHub.
2. Puja tots els fitxers d'aquesta carpeta mantenint l'estructura.
3. Ves a **Settings → Pages**.
4. A **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la branca `main` i la carpeta `/(root)`.
6. Guarda els canvis. GitHub et mostrarà l'adreça pública.
